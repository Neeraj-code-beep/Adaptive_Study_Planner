# Research Documentation

This directory contains literature reviews, theoretical foundations, and comparative analyses on Knowledge Tracing.

## Planned Documentation
1. **Knowledge Tracing Foundations:**
   - Formal definition of Bayesian Knowledge Tracing (Corbett & Anderson, 1994).
   - Parameters: Prior Mastery $P(L_0)$, Transition Probability $P(T)$, Guess Probability $P(G)$, and Slip Probability $P(S)$.
   - Hidden Markov Model (HMM) formulation and forward algorithm updates.
2. **Deep Knowledge Tracing Overview:**
   - Comparison between BKT and DKT (Piech et al., 2015).
   - Trade-offs: interpretability vs. representation capacity.
3. **Prerequisite Graph Formulation:**
   - DAG modeling of concept dependencies in Data Structures.
